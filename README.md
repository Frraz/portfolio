# Nave Digital

Documentação do portfólio de Warley Ferraz Almeida, que será publicado em [warley.ferzion.com.br](https://warley.ferzion.com.br).

**Estado:** em desenvolvimento. Veja o [ROADMAP](ROADMAP.md).

## A ideia

O portfólio é uma catedral digital à noite. Uma chuva de código cai através de uma rosácea gótica e vira a luz do vitral. Vitral e fibra óptica, o trabalho diário dele em um NOC, fazem a mesma coisa: levam luz por vidro.

O visual mira premiações de design. O texto diz a verdade: um Analista de Redes N2 que está começando em cibersegurança.

## Stack

Next.js 16, React 19, TypeScript, Tailwind v4, Base UI, GSAP com ScrollTrigger, Motion, Lenis, Three.js, React Three Fiber, Drei, Postprocessing, Blender, Lottie, Storybook, Playwright e Vitest. O site é estático e fica em contêiner nginx sem privilégios, no VPS próprio.
